**HireElite** is a comprehensive full-stack **MERN (MongoDB, Express, React, Node.js)** platform designed for clients and freelancers. It facilitates seamless job posting, dynamic application management, and secure hiring workflows with role-based dashboards.

## 🚀 Key Features

### 🏢 Client Dashboard
- **Project Lifecycle Management**: Post detailed job listings with budget and deadline specifications.
- **Application Review**: View all freelancers who have applied, with their proposals and introduction videos.
- **One-Click Hiring**: Automatically assign freelancers to projects and notify unsuccessful candidates.

### 🧑‍💻 Freelancer Dashboard
- **Global Job Search**: Browse and filter available projects across different categories.
- **Rich Proposals**: Submit applications with cover letters, proposed rates, and estimated durations.
- **Professional Profiles**: Manage your skills, experience, and video self-introductions.

### 🔔 Notification System
- **Real-time Feedback**: Automated notifications for application results and project assignments.
- **Unread Badges**: Dynamic UI indicators for new notifications on the dashboard.

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Context API, React Router, Axios.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB & Mongoose.
- **Security**: JWT, Bcrypt.js, Helmet, DOMPurify.
- **Payments**: Milestone & Hiring Logic (Razorpay-ready architectural foundation).
